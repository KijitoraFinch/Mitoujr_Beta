# 拡張

拡張は Resource の観測、Observation からの Region の解決、Region の同一性と包含の比較、注釈の検査を提供する。Core は Link と Capture を管理し、Resource ごとの方針に従って Observation を選ぶ。注釈の `check` には Link と両端の解決結果を渡す。

解決中の拡張は必要な Resource を Core に要求し、受け取った内容から次の Resource を探索できる。同じ Resource の現在は一回の操作中に固定する。提供元は観測時の実際の状態を返し、Resource を変更しない。同じ拡張が観測と解決を提供する場合も、解決中に観測要求を処理できる。

内容は Core が管理する一時ファイルで受け渡す。観測時には提供元が指定ファイルに bytes を書き、Core が内容を固定する。解決時には固定した内容のファイルと Observation メタデータを渡す。ファイルは拡張プロセスの終了まで保持する。保存済み Observation も同じ受け渡しを使う。プロトコルは [EXTENSIONS.md](../../EXTENSIONS.md) に記す。

解決・比較に使う LS や設定などの外部状態とキャッシュは拡張が管理する。Core は各解決で使った Observation を記録する。Capture は解決結果を保存するため、読み取りに拡張の起動や再解決を必要としない。

CLI 操作が拡張プロセスと一時ファイルを所有する。Tokio の非同期通信に操作全体の期限を設け、通常終了では標準入力を閉じて待機する。中断・通信破損・期限超過では補助プロセスを含むプロセス群を終了し、終了処理の結果を呼び出し元へ返す。
